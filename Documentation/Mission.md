# Mission

## Rules
- A function that is exact on only some ROM versions MAY land as a per-version match while the other versions keep assembly, and publish gates MUST NOT refuse it.
- RageWars MUST NOT be considered done until it has no placeholder identifiers, files or folders and one translation unit per original module in an original-style layout.
- RageWars MUST NOT be considered done until us, us-rev1, de, eu and eu-x each have 0 INCLUDE_ASM, 0 NON_MATCHING, all data matched, all blobs decoded and an exact ROM.
- Differences between cartridge versions MUST be real version differences, matched in shared C behind version guards and documented; a match-percent gap without one is tooling drift to fix.
